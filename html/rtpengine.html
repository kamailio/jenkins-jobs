RTPEngine Debian repositories

Info

This is the Debian/Ubuntu package repository of RTPEngine, powered by jenkins-debian-glue.org and sponsored by donations.

Usage instructions:
% wget -O- https://deb.kamailio.org/kamailiodebkey.gpg | gpg --dearmor \
| sudo tee /usr/share/keyrings/kamailio.gpg

add key info in repository definition:

deb [signed-by=/usr/share/keyrings/kamailio.gpg] http://deb.kamailio.org/rtpengine-${VER} ${CODENAME} main

Old method:

% wget -O- http://deb.kamailio.org/kamailiodebkey.gpg | sudo apt-key add -
