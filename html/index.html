Kamailio Debian repositories

Info

This is the Debian/Ubuntu package repository of Kamailio, powered by jenkins-debian-glue.org and sponsored by donations.

RTPengine builds

Usage instructions:
% wget -O- https://deb.kamailio.org/kamailiodebkey.gpg | gpg --dearmor \
| sudo tee /usr/share/keyrings/kamailio.gpg

add key info in repository definition:

deb [signed-by=/usr/share/keyrings/kamailio.gpg] http://deb.kamailio.org/kamailio${VER} ${CODENAME} main

Old method:

% wget -O- http://deb.kamailio.org/kamailiodebkey.gpg | sudo apt-key add -
