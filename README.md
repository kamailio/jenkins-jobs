README for jenkins-jobs
===============================

This repository provides the jenkins jobs configurations and scripts used by
the [Kamailio project](https://www.kamailio.org/) at
[Kamailio jenkins](https://jenkins.kamailio.org).

This work was initially sponsored by [Sipwise](http://www.sipwise.com/).
Nowadays is been sponsored thanks to direct
[donations](https://www.kamailio.org/w/donations/) to the
[Kamailio project](https://www.kamailio.org).

Involved Software
-----------------

* [Debian](https://www.debian.org/)
* [Jenkins](https://jenkins.io/)
* [jenkins-debian-glue](https://jenkins-debian-glue.org/)
* [Jenkins Job Builder](https://docs.openstack.org/infra/jenkins-job-builder/)
